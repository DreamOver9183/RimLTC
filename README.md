# RimLTC：Rim Long-Term Care（邊緣世界：長期照護）

輕量、貼合原版的 RimWorld 老年衰亡、安寧長照與技藝傳承模組。完整設計理念見 [`docs/RimLTC 模組概念設計書.docx`](docs/)。

> A lightweight, vanilla-friendly old-age, hospice care and legacy mod for RimWorld 1.6. Elderly pawns develop *Natural Senescence*, a three-stage condition that ends in a natural death. Caring for them uses only vanilla jobs and a separate hospice care policy. Good long-term care is rewarded with skilltrainers and a positive passing mood. English and Traditional Chinese are included.

## 需求與安裝

- RimWorld **1.6**
- [Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077)（需排在本模組之前）
- 把整個 repo 放進 RimWorld 的 `Mods` 資料夾即可。編譯好的 `1.6/Assemblies/RimLTC.dll` 已包含在 repo 內。
- 可以加入既有存檔。DLC 都是選配：生體生長艙需要 Ideology，基因免疫需要 Biotech。

## 功能

### 生理衰竭（Natural Senescence）
- 生物年齡達到個人門檻時發病。預設門檻是 100 歲，可改成「種族壽命期望 × 120%」；每人另加常態分佈浮動（σ = 5 歲），用 pawn ID 決定，所以每次讀檔都一樣。
- 單一 Hediff，三個階段：

| 階段 | 嚴重度 | 效果 |
|---|---|---|
| 初期虛弱 | 0.01–0.39 | 移動 −20%、疼痛 +10% |
| 臥床失能 | 0.40–0.79 | 意識上限 29%、移動上限 0（原版倒地臥床）、疼痛 +25% |
| 臨終彌留 | 0.80–0.99 | 意識上限 10%、疼痛 +40% |

- 嚴重度到 1.0 時自然離世。
- 嚴重度 ≥ 0.5 且患有原版「動脈阻塞」時，每半天有機率（預設 3%）誘發急性心臟病發作。

### 長期照護
- 餵食、清潔、照護全部使用原版工作。臥床長者每 8 小時在身旁產生原版髒污，由清潔工處理。
- **長照方針**與原版醫療方針分開設定。只有衰竭需要照護時，醫生依長照方針選藥；有外傷或疾病時，仍照原版醫療方針處理。長照永遠不會使用閃耀世界藥品。

| 長照方針 | 物資 | 效益 | 維持時長 | 照護中的惡化倍率 | 未照護時大約存活 |
|---|---|---|---|---|---|
| 放棄照護 | 不派醫護 | 0% | — | ×1.0 | 30 天 |
| 徒手安撫 | 不用藥 | 50% | 8 小時 | ×0.6 | 50 天 |
| 草藥調養 | 草藥 | 75% | 12 小時 | ×0.4 | 75 天 |
| 常規安寧 | 一般醫療包 | 100% | 16 小時 | ×0.2 | 150 天 |

- 惡化倍率 = `1 − 0.8 × 效益`，永遠大於 0，所以長者最終一定會壽終。
- 每個人工心、肺、肝、腎再減緩 10%，總計最多 50%。
- 生體生長艙完成一次「年齡逆轉」週期時，嚴重度 −0.15。
- Biotech 的 Ageless／Non-senescent 基因，以及任何在 `hediffGiversCannotGive` 列出本 Hediff 的基因，都會讓小人免疫。

### 介面
- **健康 → 概觀**：在原版醫療方針按鈕下方加一列「長照方針」。只對長者，以及年齡已達門檻 75% 的小人顯示。
- **分配分頁**：新增「長照方針」欄位。左鍵點表頭可一次設定清單中所有人，右鍵點表頭排序；格子支援拖曳批次設定。

### 技能傳承與四階善終
- 每次照護都會擲骰一次，可能在床邊產生長者最高技能的原版技能訓練器。機率 = 階段基礎率（2% / 6% / 15%）× 效益 × 照護品質 × 倍率，每次上限 75%。條件是該技能 ≥ 10 級，每位長者一生預設最多產出 1 個。
- 隱藏的**照護滿意度**（0–100，初始 45）：
  - 每次照護往該方針的上限收斂。上限為徒手 55、草藥 85、常規安寧 85；常規安寧搭配舒適床鋪且附近沒有髒污時為 100。
  - 每半天檢查一次，未受照護、倒在地上、附近有髒污都會扣分，單次最多扣 8 分。
- 長者非因外力暴力離世時，殖民者依滿意度獲得以下心情（數值可在設定中調整）：

| 滿意度 | 善終階級 | 心情 | 持續 |
|---|---|---|---|
| 0–29 | 孤獨枯萎 | −12 | 6 天 |
| 30–59 | 遺憾離世 | −4 | 4 天 |
| 60–89 | 安詳善終 | −2（60–74）／+2（75–89） | 4 天 |
| 90–100 | 圓滿典範 | +5 | 6 天 |

## 模組設定

設計書第七章列出的所有項目都可在「選項 → 模組設定 → RimLTC」中調整，分為五區：壽命與觸發、照護與資源、傳承與善終、疾病與科技、適用對象（可另外勾選囚犯與殖民地動物；動物一律用壽命期望計算）。另外還可以設定新長者的預設長照方針（預設為草藥調養），以及重設為預設值。

## 與設計書的差異

| 議題 | 實作做法 |
|---|---|
| 照護效果 | 設計書寫草藥 0.00、醫療包 −0.05，等於可以無限延命。實作改為 `1 − 0.8 × 效益`，照護只能減緩、不能逆轉 |
| 每日惡化 | 由「未照護基準存活天數」決定（預設 30 天，約 0.033/天）。表格中的 0.10 只當作示意 |
| 照護時長 | 基礎時長 × 2/3、1、4/3，也就是 8／12／16 小時 |
| Harmony 補丁 | 共 5 處：`FindBestMedicine`、`DoTend`、`DrawOverviewTab`、`Pawn.Kill`、生長艙。「放棄照護」改用自訂 Hediff 類別處理，不額外加補丁 |
| 善終心情 | 只在非外力暴力死亡時發放 |

## 已知限制

- 原版醫療方針設為「不照護」時，原版的入口檢查會讓醫生完全不照護該小人，此時長照方針也不會生效。
- 1.7 尚未正式支援。在 1.7 中會沿用 1.6 的組件（見 `LoadFolders.xml`），可以用 `-p:RimWorldVersion=1.7` 另行編譯。
- 健康分頁的按鈕位置是用 transpiler 掛在原版醫療方針按鈕之後。若遊戲版本或其他模組改變了這段 UI，會自動改為顯示在概觀最下方。

## 開發

```bash
# 需要 .NET SDK 8+；RimWorld 與 Harmony 的參考組件由 NuGet 提供
dotnet build Source/RimLTC/RimLTC.csproj -c Release          # 輸出到 1.6/Assemblies
dotnet build Source/RimLTC/RimLTC.csproj -c Release -p:RimWorldVersion=1.7   # 輸出到 1.7/Assemblies
```

開啟開發者模式後，Debug actions 的「RimLTC」分類提供下列測試工具：
- 加上或移除衰竭。
- 直接跳到某個階段（0.20／0.50／0.95）。
- 設定照護滿意度（20／50／80／95）。
- 輸出照護狀態到 log。
- 強制產生傳承訓練器。
- 立即執行年齡掃描。

### 遊戲內測試清單
- [ ] 加上衰竭後三階段表現正確，Stage 2 起倒地臥床，並被救援上床。
- [ ] 四種方針下醫生的用藥行為正確；長者受傷時改依原版醫療方針。
- [ ] 臥床時產生髒污，清潔工會處理。
- [ ] 健康分頁的長照方針按鈕位置正確；分配分頁欄位與表頭批次設定可用。
- [ ] 四階善終心情依滿意度發放；暴力死亡時不發放。
- [ ] 床邊產生技能訓練器，且有終身上限。
- [ ] 仿生器官減免、生長艙扣除、Ageless 基因免疫都有效。
- [ ] 設定頁每個滑桿與開關都有實際效果。
